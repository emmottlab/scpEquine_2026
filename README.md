# scpEquine_2026

Scripts used for data analysis and production of the figures in the "Single Cell Proteomics characterise Age- and Sex-related Variability in Equine Adipose-derived Mesenchymal Stem Cells" manuscript.


Mesenchymal stem/stromal cell (MSC)-based therapies demonstrate variable clinical outcomes, with donor-related factors potentially contributing to functional heterogeneity. Single-cell proteomics provides a novel approach to characterise this variability at cellular resolution. To investigate the influence of donor age, sex and breed on the proteomic profiles of equine adipose-derived MSCs using single-cell proteomics.
